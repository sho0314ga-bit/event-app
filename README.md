# Event App

イベント情報を登録・管理できるWebアプリです。

## 主な機能

- イベントの追加
- イベントの編集
- イベントの削除
- お気に入り登録
- イベント検索
- 開催日順の並び替え
- 過去・本日・明日・3日以内のイベント表示

## 使用技術

- HTML
- JavaScript
- Node.js
- Express
- SQLite
- Git / GitHub
- Railway

## データ保存

SQLiteを使用しています。

ローカル環境では `events.db`、
RailwayではVolume上のSQLiteデータベースを使用しています。
