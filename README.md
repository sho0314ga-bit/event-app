# Event App

イベント情報を登録・管理できるWebアプリです。

イベント名、会場、開催日、当落日などを登録し、
検索・お気に入り・開催日による絞り込みなどができます。

## 公開URL

https://event-app-production-a2b7.up.railway.app/

## 主な機能

- イベントの追加
- イベントの編集
- イベントの削除
- お気に入り登録 / 解除
- お気に入りイベントのみ表示
- イベント検索
- 開催日順の並び替え
- 過去のイベント表示
- 本日開催のイベント表示
- 明日開催のイベント表示
- 3日以内のイベント表示
- お気に入りの開催予定イベント表示
- スマートフォン表示対応

## アプリの構成

ブラウザから `fetch()` を使用してAPIへアクセスし、
Node.js / Expressのサーバー側でSQLiteのデータを操作しています。

主に以下のAPIを使用しています。

- GET `/events`
- POST `/events`
- PATCH `/events/:id`
- DELETE `/events/:id`

## データ保存

SQLiteを使用しています。

ローカル環境では `events.db` を使用し、
RailwayではVolume上にSQLiteデータベースを配置しています。

これにより、Railwayで再デプロイしても
登録したイベントデータが残るようにしています。

## 実装で工夫した点

### 入力値のチェック

イベント名・会場・開催日は必須項目として、
フロントエンドとバックエンドの両方で入力値を確認しています。

空白だけの入力も `trim()` を使用して拒否するようにしています。

### 編集処理

編集時にキャンセルされた場合は、
`null` を確認して処理を終了するようにしています。

### エラー処理

データ取得時にエラーが発生した場合は、
`.catch()` を使用してエラーを処理し、
利用者にもエラーメッセージを表示します。

### SQLiteの永続化

Railway Volumeを使用して、
SQLiteのデータを再デプロイ後も保持できるようにしています。

## 開発目的・学習方法

Webアプリ開発の基礎を理解することを目的に制作しました。

JavaScript、Node.js、Express、API、SQLite、Git、デプロイなどについて、
単にコードを動かすだけではなく、処理の意味やデータの流れを確認しながら実装しています。

開発ではAIも補助ツールとして活用していますが、
生成されたコードをそのまま使用するのではなく、
コードの役割を確認し、エラーの原因を調べ、
実際に動作確認・修正を繰り返しながら理解を深めています。

特に、フロントエンドとバックエンドの入力チェック、
HTTPステータス、API通信、SQLiteの永続化などは、
実際にエラーを発生させて挙動を確認しながら実装しました。
